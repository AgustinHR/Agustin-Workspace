# Computer Requirments 
Operating System: CARLA is built for Windows 10 and 11 and Ubuntu 20.04 and 22.04. \
An adequate GPU :We recommend a dedicated GPU equivalent to an NVIDIA 2070 or better with at least 8Gb of VRAM or more. \
Disk space: CARLA will use about 20 GB of disk space. \
Two TCP ports: Ports 2000 and 2001 by default. Make sure that these ports are not blocked by firewalls or any other applications. \

# Set Up 
Download Carla: https://carla.readthedocs.io/en/latest/start_quickstart/#carla-installation \
Download Python Version 3.12: https://www.python.org/downloads/release/python-31210/ \
PIP: Python package manager version 20.3 or higher.

# How To Run Program
1. Go to the Carla directory
2. Execute Carla.exe
3. Open another terminal and run file (python main.py)
